# 기타 연습 루틴 생성기

이 앱은 기본 연습은 오프라인으로 가능하지만, 곡 검색은 iTunes 공개 검색 API를 사용하므로 인터넷 연결이 필요합니다. 기존 루틴 개수 모드와 곡 길이 기반 시간 모드를 모두 지원합니다.

## 기능 요약

- `iTunes Search API`로 곡 제목 또는 가수를 검색합니다.
- 검색 결과에서 곡명, 가수, 앨범, 재생 시간(`trackTimeMillis`)을 읽어 표시합니다.
- 선택한 곡의 길이를 분:초 형식으로 계산해 연습 목표 시간을 설정할 수 있습니다.
- 시간 모드에서는 곡 길이의 1배, 2배, 3배 중 선택해 목표 연습 시간을 자동 계산합니다.
- 곡 BPM을 직접 입력해 해당 BPM 기준으로 연습 패턴을 생성합니다.
- 기존 크로매틱 패턴 생성과 메트로놈 기능은 그대로 유지합니다.
- 곡 길이 정보가 없으면 사용자에게 직접 `분:초` 형식으로 입력할 수 있습니다.
- 검색 중엔 UI가 멈추지 않고, 연결 실패와 빈 검색어도 처리합니다.
- API 키는 필요하지 않습니다. iTunes 공개 검색 API만 사용합니다.

## 실행

```powershell
uv sync --locked
uv run main.py
```

## 검사

```powershell
uv run python -m py_compile main.py routine.py view.py
```

## 동작 방식

1. 왼쪽 설정에서 연습 모드를 선택합니다.
   - 루틴 개수 모드: `루틴 개수`, `반복 횟수`, `BPM 범위`로 연습
   - 곡 길이 기반 시간 모드: 곡 길이에 따라 목표 연습 시간을 계산하고, 곡 BPM으로 연습 속도를 맞춤
2. 곡 검색 영역에서 제목 또는 가수로 곡을 찾고 선택합니다.
3. 검색 결과의 `trackTimeMillis`를 읽어 `분:초`로 표시하고, 시간 배수(1x, 2x, 3x)를 선택합니다.
4. 시간 모드에서는 별도 `곡 BPM` 입력란을 사용해 세션의 BPM을 고정합니다.
5. 시작하면 기존 크로매틱 연습 패턴과 메트로놈이 동작합니다.
6. 시간 모드에서는 목표 시간이 되면 메트로놈과 타이머를 종료합니다.
7. 세션 종료 기록에는 선택한 곡, 곡 길이, 목표 연습 시간, 실제 연습 시간이 포함됩니다.

## 파일별 역할

- `main.py`: 세션 제어, 타이머, 검색/결과 처리, 시간 모드 로직, 세션 종료 기록
- `view.py`: Tkinter UI 구성, 설정 패널, 검색 폼, 스크롤 인터페이스, 메트로놈 표기 영역
- `routine.py`: 크로매틱 연습 패턴 생성, 손가락 순서, 방향, BPM, 반복 횟수 로직
- `api-plan.md`: 기능 기획 문서
- `.gitignore`: Python 산출물, 가상환경, 환경 변수 파일 제외

## 주요 로직과 한계

- 실제 검색은 iTunes 공개 API를 사용하므로 별도 API 키가 필요하지 않습니다.
- 루틴 모드에서는 최소/최대 BPM 범위를 사용해 랜덤 BPM 연습이 이루어집니다.
- 시간 모드에서는 곡 길이와 배수를 기반으로 목표 시간을 계산하며, 곡 BPM으로 연습 속도를 고정합니다.
- 곡 길이 정보가 없거나 유효하지 않으면 `분:초` 수동 입력을 사용합니다.
- 인터넷 연결이 실패해도 기존 루틴 모드는 사용 가능하며, 검색/시간 모드는 제한됩니다.
- 현재 구현은 로컬 데스크톱 Tkinter 앱이며, 외부 웹 서버나 백엔드가 없습니다.
