# 기타 연습 루틴 생성기

Python 표준 라이브러리만 사용하는 오프라인 데스크톱 프로그램입니다. Windows에서는 Tkinter 화면과 `winsound` 박자를 사용하며, 인터넷이나 외부 파일은 필요하지 않습니다.

## 실행

```powershell
python main.py
```

앱에서 진행할 루틴 개수(1~30개), 모든 루틴에 적용할 반복 횟수(1~100회), 난이도(Easy / Medium / Hard), BPM 범위(40~240)를 설정한 뒤 시작하세요. 각 루틴은 6개 줄을 손가락 패턴으로 연주하는 반복이 끝나면 자동으로 다음 루틴으로 넘어갑니다. 마지막 루틴을 마치면 세션 기록 알림이 뜨고 입력 화면으로 돌아와 새 세션을 시작할 수 있습니다. `세션 종료 및 기록 보기`로 중간 종료할 수도 있습니다.

## 패턴 검사

```powershell
python routine.py
```

난이도별로 무작위 패턴 300개를 만들어 운지, 프렛, 줄 방향, BPM, 반복 횟수 조건을 확인합니다. GUI와 패턴 생성 코드는 별도 Python 파일로 나뉘어 있습니다.
